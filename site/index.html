How it works

Press. See. Pick.

Three things, and your hand never leaves the mouse. If both hands are on the keyboard, the same three things happen from a shortcut.

  • 01 Press

    Any mouse, any button.

    Middle-click works with no setup. For a thumb or side button, press Detect Button and then press it — VortexFlow watches earlier in the input pipeline than most mouse utilities, so buttons other apps can’t see usually still work.

  • 02 See

    Every window, around the pointer.

    Each window is its own card — including minimized ones, other Spaces, and full-screen apps. Browser windows show the icon of the site that is open in them, so three Chromes look like three different things.

  • 03 Pick

    Flick, release, done.

    The window you were just in is the second card, already under the pointer. Or start typing to filter by app, title, tab host, or URL path — and launch an app that isn’t running without leaving for Spotlight.

What it does

Built for desks with too many windows.

Cmd-Tab switches applications. VortexFlow switches windows and tabs — the thing you actually wanted — and treats the mouse as a first-class way to do it.

  • Every window is a card

    Four Finder windows are four cards, each with its own title, thumbnail, and place in the recency order — not one icon hiding four things.

  • Same-app windows look different

    Cards take a hint of colour from their icon, and browser windows show the site’s own icon layered on the browser’s. Three Chromes, three faces.

  • Any mouse, any button

    Middle-click with no setup, or Detect Button for a side or thumb button. Works with buttons other utilities can’t even see.

  • Keyboard optional

    A global shortcut opens the same spiral. Press it again to close. Both hands on the keys, same result.

  • Five layouts

    A strip, a grid, a list with a large preview, and two round arrangements that fan around the cursor. Live screenshots or large icons in each.

  • Real previews

    Thumbnails come from ScreenCaptureKit, captured when the overlay is up, never saved. The selected card keeps refreshing.

  • Spaces, minimized, full screen

    Windows on other desktops, hidden in the Dock, or full screen are all in the spiral. Nothing is out of reach because of where it lives.

  • Type to narrow it down

    Filter by app, title, tab host, or URL path. Apps that aren’t running show up too, so you can launch one without leaving for Spotlight.

Also: a right-click menu with live preview, tab search, media controls, and window placement — below. And the full list is in the README.

Type it. The spiral still has an answer.

Filter by app, title, tab host, and URL path. If nothing local matches, search the web, open the first result, or send the query to ChatGPT, Claude, or Grok — without leaving the overlay.

Right-click a card

The rest of the window, without hunting for it.

A live preview. Search through Tabs on Chrome, Safari, Edge, Brave, Arc, Comet and Chromium — including other desktops. Play / pause / next if something is playing. Move & Resize, Fill & Arrange, Full Screen, Move to Display. Full-screen windows leave the Space first, then place — so a live-share window can come off a shared screen.

Open source

Free, MIT-licensed, and built in the open.

VortexFlow is a native Swift and AppKit app with no third-party dependencies — the spiral, the event taps, the tab search, all of it — and the whole thing is on GitHub under the MIT license. Read it, fork it, or fix the one thing that annoys you. A window switcher lives in the most private part of your Mac; you should be able to see exactly what it does there.

    Questions

    Is this for me?

    If you keep a handful of apps and Cmd-Tab is fine, no. If you live in many windows, many Chromes, Spaces, and a mouse that already has a spare button, yes.

    Is it really free?

    Yes. VortexFlow is open source under the MIT license. There is no paid tier, no trial, no license key, and no account. Download the build or compile it yourself — either way it is the same code.

    Does it send anything anywhere?

    No analytics and no telemetry. The one network request it makes is to fetch a site’s icon so a browser window can show what is open in it — unauthenticated, no cookies, and never for a private window. Deny it network access and everything still works minus the icons. The whole policy is short.

    Why does macOS say the developer can’t be verified?

    The app is signed but not notarized, because notarization needs a paid Apple Developer account. Open System Settings → Privacy & Security and choose Open Anyway. You do it once. Or build from source and skip Gatekeeper entirely. Step by step.

    Where should I download it from?

    Only from this site or from GitHub Releases. VortexFlow asks for Accessibility, Input Monitoring, and Screen Recording — exactly the permissions a tampered copy would love to have. If you found it anywhere else, don’t run it; get it here or build it from source.

    How can I help?

    Use it on a real desk and report what breaks — especially mice and browsers we have not seen. Pull requests are welcome; the codebase is plain Swift with a large test suite, so most changes come with a test. Stars help other people find it.

    Does this replace Cmd-Tab?

    No. Cmd-Tab still exists. VortexFlow is a spiral at the cursor. A keyboard shortcut does the same job if both hands are on the keys.

    How is this different from AltTab?

    AltTab is a keyboard window switcher — Windows Alt-Tab on a Mac. VortexFlow is a spiral of windows at the cursor that also works from a shortcut. Longer comparison.

    Does middle-click still open links?

    Not while VortexFlow owns middle-click — it has to consume the button or the click would land underneath. Move to a side button in Settings, or use the keyboard shortcut and leave middle-click alone.
