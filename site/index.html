Questions

Is this for me?

If you keep a handful of apps and Cmd-Tab is fine, no. If you live in many windows, many Chromes, Spaces, and a mouse that already has a spare button, yes.

Do I need a credit card?

No. The preview is free and limited-time. You create an account, use it, then decide.

Do I need an account?

Yes. Create one when you open the app. That’s how the preview starts.

Does this replace Cmd-Tab?

No. Cmd-Tab still exists. VortexFlow is a spiral at the cursor. A keyboard shortcut does the same job if both hands are on the keys.

How is this different from AltTab?

AltTab is a keyboard window switcher — Windows Alt-Tab on a Mac. VortexFlow is a spiral of windows at the cursor that also works from a shortcut. Longer comparison.

Does middle-click still open links?

Not while VortexFlow owns middle-click — it has to consume the button or the click would land underneath. Move to a side button in Settings, or use the keyboard shortcut and leave middle-click alone.
