Install

  1. Open the disk image and drag VortexFlow to your Applications folder.
  2. Open it. The first time, macOS will refuse — see Gatekeeper below. You do this once.
  3. Grant the permissions it asks for. Each one is optional and explained; the app runs with any subset.
  4. Press middle-click, or the shortcut. The spiral appears around the pointer.

Gatekeeper: “the developer cannot be verified”

VortexFlow is signed, but it is not notarized, because notarizing requires a paid Apple Developer account. macOS therefore refuses to open it the first time. That is expected, and the fix takes a moment:

  1. Open the app. macOS will refuse. Leave that dialog.
  2. Open System Settings → Privacy & Security, scroll to Security, and click Open Anyway next to VortexFlow. Authenticate when asked.
  3. Open the app again. It launches, and stays launchable.

On macOS 15 and later, right-clicking the app and choosing Open no longer works as a shortcut for this; Apple removed that bypass. See Apple’s own documentation. If you would rather not click Open Anyway on something you did not compile, the section below is for you.

Build from source

The repository is a Swift package with no third-party dependencies. You need macOS 15 or later and the Xcode command-line tools (xcode-select --install). The build script compiles the package, assembles the .app bundle, signs it, and — with --install — replaces the copy in Applications.

# clone, build, install
git clone https://github.com/maheshauti96/VortexFlow.git
cd VortexFlow
Scripts/build-app.sh --install

# run the tests
swift test

A locally built app is signed with an ad-hoc identity by default, which means macOS ties its privacy permissions to that exact binary and asks again after every rebuild. If you plan to rebuild often, run Scripts/create-signing-certificate.sh once to create a stable local certificate; the build script picks it up automatically. To produce a disk image like the one on the releases page, run Scripts/make-dmg.sh.

Verify what you downloaded

Every release on GitHub lists its assets with their SHA-256 digests. To check a disk image against them:

shasum -a 256 ~/Downloads/Vortexflow-*.dmg

Because the source is public, you can also skip the question entirely and build the same code yourself.

Uninstall

Quit VortexFlow from the menu bar icon and drag it out of Applications. Its settings live in ~/Library/Preferences/io.vortexflow.Vortexflow.plist; delete that too if you want no trace left. Nothing else is written anywhere.
