Compare

The empty gap is the cursor.

Window switchers for Mac are a crowded shelf. Almost all of them replace Cmd-Tab, and most of them are for everyone. VortexFlow is not. It is a spiral around the pointer for people who already have too many windows.

Cmd-Tab, Cmd-`, Mission Control

Cmd-Tab switches applications, not windows. Five Chrome windows are still one Chrome. Cmd-` cycles windows of the current app in the current Space, and skips fullscreen. Mission Control shows everything as stamps. None of them start from the pointer.

Dory

Dory is the closest feel on the mouse: a button overlay, radial layouts, a letter to jump. A CNET review put the limit in the cons: it doesn’t handle individual windows or browser tabs. VortexFlow is the spiral of windows that question was asking for.

AltTab

The default keyboard window switcher. Live thumbnails, Option-Tab. Search is a Pro feature. It is not a spiral at the cursor, and not extra-button detection. If you want Windows Alt-Tab on a Mac, use AltTab.

BetterCmdTab

A complete Cmd-Tab replacement: search, launch, tab drill-in, tiling. Still a Cmd-Tab replacement. It is not a spiral at the pointer. No Detect Button, no site-favicon compositing, no web/assistant fallback in the same overlay.

DockDoor

Live previews when you hover the Dock. Excellent at “which of the ten Safari windows.” The overlay lives on the Dock. You still travel to the Dock.

Witch, Contexts, Hop, Raycast, WOS

Witch is explicit: “⌘-Tab Everything.” Contexts collects usage metrics. Hop is a visual Alt-Tab. Raycast’s window switcher is a text list. WOS reinvents Cmd-Tab for tabs-as-first-class. All keyboard-first. None of them are a spiral of every window and tab at the cursor that also works from a shortcut.

What VortexFlow will not claim

We are not the only window switcher, the only search, or the only private one. We are the spiral at the cursor, for any mouse and any keyboard, with extra-button detection, favicon compositing so same-app windows don’t look the same, tab search by host and path including other Spaces, and a web/assistant fallback when nothing local matches.
